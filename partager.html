📡 Partager : votre propre site radioamateur

Ce site vous plaît ? Tout OM peut le réutiliser gratuitement pour sa propre station ou son club. C'est un site statique simple (HTML/CSS/JS), hébergé gratuitement sur GitHub Pages, sans traceur, sans cookie et sans base de données.

Ce que vous obtenez

  • Page d'accueil façon transceiver rétro (VFO, S-mètre, PTT CW, easter egg CQ qui ouvre le formulaire QSL)
  • Bascule français / anglais, français par défaut
  • Outils station, relais, locator Maidenhead et CW
  • Liens WebSDR et température au QTH (Open-Meteo, d'après le locator)
  • Carte QSL interactive et demande d'e-QSL, avec confirmation automatique bilingue
  • Message d'erreur visible si un champ du formulaire est invalide
  • Formulaire de contact (FormSubmit), bouton de don PayPal, modèle de mentions légales
  • Articles APRS et packet radio

Comment faire (sans savoir coder)

  1. Créez un compte GitHub gratuit.
  2. Ouvrez le modèle et cliquez sur Use this template (ou Fork).
  3. Modifiez le seul fichier config.js directement sur github.com : indicatif, nom, locator, e-mail, station, relais, club…
  4. Activez Settings → Pages.
  5. Envoyez-vous un message via le formulaire et confirmez l'e-mail d'activation de FormSubmit.
  6. Adaptez les mentions légales à votre situation. En option : liez votre propre nom de domaine.

➜ Ouvrir le modèle sur GitHub

Le guide pas à pas complet est dans le README du modèle. Des questions ? Utilisez le formulaire de contact.
